### Домашнее задание
1. Создай абстрактный класс `Animal` с чисто виртуальной функцией `makeSound`.
2. Напиши два производных класса, например, `Dog` и `Cat`, каждый реализует свою версию `makeSound`.
3. В одном из классов добавь инкапсулированное поле (например, имя животного), реализуй методы доступа (getter/setter).
4. Создай вектор указателей на `Animal`, добавь туда объекты обоих классов, вызови их `makeSound` в цикле.
5. Сформулируй кратко на примере кода, как каждый принцип ООП используется.
### Решение задания
```cpp
#include <iostream>
#include <vector>
#include <string>

class Animal {
public:
    virtual void makeSound() = 0;
    virtual ~Animal() {}
};

class Dog : public Animal {
private:
    std::string name;
public:
    Dog(const std::string& n) : name(n) {}
    void setName(const std::string& n) { name = n; }
    std::string getName() const { return name; }

    void makeSound() override {
        std::cout << getName() << " говорит: Гав-гав!" << std::endl;
    }
};

class Cat : public Animal {
public:
    void makeSound() override {
        std::cout << "Кошка говорит: Мяу!" << std::endl;
    }
};

int main() {
    Dog dog("Шарик");
    Cat cat;

    std::vector<Animal*> animals;
    animals.push_back(&dog);
    animals.push_back(&cat);

    for (Animal* a : animals) {
        a->makeSound();
    }

    dog.setName("Барбос");  // изменяем имя через setter
    dog.makeSound();

    return 0;
}
```

***
### ООП-принципы в этом задании

- **Абстракция**: `Animal` задаёт общий интерфейс для всех животных через чисто виртуальную функцию `makeSound`.
- **Наследование**: `Dog` и `Cat` наследуют поведение от `Animal`.
- **Инкапсуляция**: В классе `Dog` поле `name` скрыто, доступ к нему возможен только через методы.
- **Полиморфизм**: Можно хранить разных животных в одном векторе и вызывать их методы через одинаковый интерфейс.
