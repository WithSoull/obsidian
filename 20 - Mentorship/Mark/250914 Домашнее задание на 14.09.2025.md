## **Задача 1**
На вход подаётся натуральное число N. Удалите из его записи все чётные цифры (0, 2, 4, 6, 8), сохранив порядок остальных цифр. Выведите полученный результат. Если все цифры оказались удалены, выведите 0.

**Пример 1**
```
Ввод: 2405638  
Вывод: 53
```

**Пример 2**
```
Ввод: 86420  
Вывод: 0
```

## **Задача 3 (усложнённая)**
Дано сообщение, состоящее из слов, разделённых пробелами. Требуется:
1. Найти все слова, начинающиеся на букву «a» (латиница).
2. Среди них удалить **самое длинное**.
3. Если таких несколько — удалить **первое** из них.
4. Если слов на «a» нет, а всего слов в сообщении больше трёх — удалить **самое короткое слово** в сообщении.
5. В противном случае вывести сообщение без изменений.

**Пример 1**
```
Ввод: apple banana apricot orange  
Вывод: banana apricot orange
```

**Пример 2**
```
Ввод: hello world python code  
Вывод: hello world python
```

**Пример 3**
```
Ввод: one two three  
Вывод: one two three
```
