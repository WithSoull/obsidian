``` python
"""
Для узла с IP-адресом 111.91.200.28 адрес сети равен 111.91.192.0. 
Найдите наименьшее возможное количество нулей в двоичной записи маски подсети.
"""


import ipaddress

zero_bits = 100

ip_node = ipaddress.IPv4Address('111.91.200.28')
network_address = ipaddress.IPv4Address('111.91.192.0')

ip_node_int = int(ip_node)
network_int = int(network_address)

for prefix_length in range(33):
    mask_bin = '1' * prefix_length + '0' * (32 - prefix_length) 
    mask_int = int(mask_bin, 2)
    if (ip_node_int & mask_int) == network_int:
        zero_bits = min(32 - prefix_length, zero_bits)

print(f"Наименьшее количество нулей в маске: {zero_bits}") # 12
```

Мое решение 4-ой задачи:
``` python
'''
Сеть задана IP-адресом 112.208.0.0 и сетевой маской 255.255.128.0.
Сколько в этой сети ІР-адресов, для которых количество единиц в двоичной записи IP-адреса кратно 11?
В ответе укажите только число.
'''

import ipaddress
#                                    IP     /     маска
network = ipaddress.IPv4Network('112.208.0.0/255.255.128.0')

# Функция подсчёта количества единиц в двоичном представлении числа
count_ones = lambda x: bin(x)[2:].count('1')

count = 0
for ip in network:
    if count_ones(int(ip)) % 11 == 0:
        count += 1

print(count)
```

``` python

```

Тут у нас адрес для сети будет выглядеть след образом `118.187.59.255/5`, тут сначала идет IP-адрес узла, который находится в этой сети (в ip1 можно передать как строчку так и объект `IPv4Address`,  я передавал именно его, а получил его вот так - `ip1 = ipaddress.IPv4Address('118.187.59.255')` ), а потом маска, которая у нас будет перебираться от 0 до 32.


Это как раз условие на то что наш ip1 не является адресом сети И наш ip1 не является широковещательным каналом (broadcast). Получить все это дело можно из полей класса `IPv4Network`, это наш объект `net1`. Ну и надо проверить что ip2 не является служебным для своей уже сети.
