### Задача 24.1

```python
s = open("./24.1.txt").read()

cur = 0
mx = 0

for i in range(1, len(s)):
    if s[i - 1] in "ABC" and s[i] in "ABC":
        cur = 1  # новая цепочка начинается, если подряд идут буквы из набора ABC
    else:
        cur += 1  # продолжаем текущую цепочку

    if cur > mx:
        mx = cur  # обновляем максимум

print(mx)
```

### Задача 24.2

![[99 - Meta/02 - Медиа/Pasted image 20251224212210.png]]

#### Первое решение (с циклом while)

```python
s = open("./24.2.txt").read()

cur = 0
mx = 0
i = 0

while i < len(s) - 1:
    pair = s[i:i+2]
    if pair == "AB" or pair == "CB":
        cur += 1      # увеличиваем длину текущей цепочки
        i += 1        # пропускаем одну позицию, чтобы не перескакивать через пару
        if cur > mx:
            mx = cur
    else:
        cur = 0       # сбрасываем счётчик при разрыве последовательности

    i += 1

print(mx)
```

#### Второе решение (с заменой)

```python
s = open("./24.2.txt").read()

# заменяем нужные пары на символ '*'
s = s.replace("AB", "*")
s = s.replace("CB", "*")

cur = 0
mx = 0

for i in range(len(s) - 1):
    if s[i] == "*":
        cur += 1
    else:
        cur = 0

    mx = max(mx, cur)

print(mx)
```
