###### Вариант 1 (твой)
``` python
def pr(n):
    s = ''
    while int(n):
        s += str(n % 8)
        n = n // 8
    return s[::-1]

r = pr(7 * 512**120 - 6 * 64**100 + 8**210 - 55)
c = r.count('0')
print(c) # 150 (неверно, ошибка по невнимательности, неправильно переписал число в конце 55 а не 255)
```

Правильное решение:
``` python
from string import ascii_lowercase
alphabet = "0123456789" + ascii_lowercase

def perevod(x: int, k: int) -> str:
    s = ""
    while x:
        s = alphabet[x % k] + s
        x //= k
    return s

ans = []
number = 7 * 512**120 - 6 * 64**100 + 8**210 - 255
for base in range(2, 37):
    s = perevod(number, base)
    if '001' in s[-3:]:
        ans.append(base)

print(max(ans))
```
