# Interview Prep

~3 часа в день в Фазе 1. Цель — проходить стандартные секции, а не «выучить всё».

## Алгоритмы

- [ ] ~150 задач LeetCode medium на Go: массивы и хеши, два указателя, sliding window, стек, деревья, графы (BFS/DFS), бинпоиск, heap, базовое DP.
- [ ] Каждую задачу проговаривать вслух: сложность, граничные случаи, тесты.
- Шаблон заметки: `99 - Meta/01 - Шаблоны/Задача LeetCode.md`.

## Go

- [ ] Планировщик (G/M/P), горутины, preemption.
- [ ] Каналы: устройство, блокировки, `select`, закрытие.
- [ ] `map`, slice, строки — внутреннее устройство и подводные камни.
- [ ] GC, escape analysis, профилирование (`pprof`).
- [ ] `sync`: `Mutex`, `RWMutex`, `Once`, `WaitGroup`, atomic; data race и race detector.
- [ ] `context`, graceful shutdown, ошибки.

## Python (для Python-вакансий)

- [ ] asyncio, GIL, генераторы, декораторы, контекстные менеджеры.
- [ ] FastAPI/Django — то, что требует конкретная вакансия.

## Базы данных

- [ ] Индексы: B-tree, составные, покрывающие; когда индекс не используется.
- [ ] Транзакции, уровни изоляции, аномалии, MVCC.
- [ ] `EXPLAIN`, N+1, пагинация (keyset — уже есть живой пример из Postbox).
- [ ] Репликация и failover — есть живой опыт из mysync.

## System design

- [ ] Базовый каркас ответа: требования → API → модель данных → масштабирование → отказы.
- [ ] Кэширование, очереди (Kafka), идемпотентность, retries, rate limiting.
- [ ] 5–6 классических задач: URL shortener, чат, ленты, rate limiter, нотификации, объектное хранилище (OpenS3 — свой пример).

## Истории из опыта (STAR)

Подготовить по 2–3 минуты на каждую: ситуация → задача → действия → результат → чему научился.

- [ ] **mysync, failover при потере кворума** — сетевые разрывы между ДЦ, fault injection на 5 узлах. Материал: [[50 - Expreince/Mysync|Mysync]].
- [ ] **mysync, ложные алерты** — реплика при загрузке тяжёлого binlog.
- [ ] **Postbox, ETag + CAS** — нашёл проблему без ТЗ, сохранил обратную совместимость.
- [ ] **Postbox, adaptive MX resolver** — от гипотезы и метрик до production.
- [ ] **Работа без ментора и ревью** — как продвигал PR, чему научился. Подавать без обиды на команду.
- [ ] **OpenS3** — работа в команде, конкурентный доступ, observability.
