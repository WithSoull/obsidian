# Диплом OpenS3

Актуальный текст — [[Диплом|Диплом по ГОСТ]], порядок работы — [[План до предзащиты|план до предзащиты]].

## Сборка

Из этой папки:

```sh
make diploma
```

Результат первого запуска: `build/Диплом_ГришинИД_v001.docx`. Каждый запуск создаёт новую версию: `v002`, `v003` и далее. Номер равен максимальному существующему номеру в папке сборки плюс один; предыдущие файлы сохраняются. При ошибке конвертации незавершённый файл удаляется. Используется локальный `~/md2gost/.venv/bin/md2gost`, без `--paginate` и без титульного блока; оглавление включено. Номера оглавления обновляются в Word. Для сборки нужны установленный md2gost и его зависимости, включая Pandoc.

Другой путь к конвертеру или выходному файлу:

```sh
make diploma MD2GOST=/путь/к/md2gost
make diploma BUILD_DIR=/tmp/diploma
```

Схемы: PNG находятся в `images/`, исходники draw.io — в `images/src/`. Экспорт схем при установленном draw.io:

```sh
sh images/src/render.sh
```

## Материалы

| Папка | Содержимое |
| --- | --- |
| `10 - Drafts` | Отдельные фрагменты текста, варианты темы, материал для технологического раздела |
| `20 - Research` | Математика, литература, обзор хранилищ, параметры эксперимента |
| `20 - Research/Data/Meta CDN` | Фрагмент трассы, скрипт анализа и описание воспроизведения |
| `30 - Reviews` | Спецификации правок и проверка правил оформления |
| `30 - Reviews/Teacher` | Первоисточники лекций в `raw/` |
| `40 - Guidelines` | Структура ВКР, памятки преподавателя и правила оформления |
| `90 - Archive` | Ранний текст, версия до ревью 20.10.2026, исходная переписка и PDF-рецензия |
| `images` | Рисунки диплома и редактируемые исходники |
| `build` | Версии Word-документа |

Архивные тексты и отдельные фрагменты не входят в сборку: единственный входной файл — `Диплом.md`. Старые выгрузки DOCX, пустые документы и временный файл Word удалены; ранее закоммиченные версии доступны в истории Git.
