# План ВКР

## Структура работы

1. **Аннотация.**
2. **Введение.**
3. **Основная часть.**
4. **Заключение.**
5. **Приложение.**

Порядок написания: **основная часть → введение → заключение → приложение → аннотация**.

В составе ВКР указать количество страниц, рисунков, таблиц и т. д.

## Полный план

### 1. Аннотация — 1 страница

- Что?
- Зачем?
- С помощью чего?
- Что получилось, что было реализовано в итоге?
- Краткое описание каждого раздела.

### 2. Введение — 1–2 страницы

- Задача (проблема) и актуальность работы.
- Существующие и предлагаемые методы решения.
- Объект и предмет исследования.

### 3. Литературный обзор — 1–3 страницы

- Взять 3–4 основных источника:
  - первый описывает саму проблему;
  - второй — инструмент реализации;
  - третий — общий вывод.
- Если такая схема не получается, добавить ещё 1–2 источника с решением проблемы.
- Для каждого источника описать детали, достоинства и его пользу для данной работы.

### 4. Исследовательский раздел — 15–20 страниц

#### Анализ предметной области

Проанализировать компоненты области знаний, которые описывают:

- саму проблему;
- способы её решения;
- основные термины;
- правила и законы.

#### Анализ аналогов — существующих решений

- Описать от двух до пяти полных или частичных аналогов: $1 < N \leq 5$.
- Частичный аналог — решение, которое имеет только часть требуемой функциональности, лишь частично решает задачу либо работает только при определённых условиях и дополнениях.
- Для каждого аналога проанализировать:
  - достоинства;
  - недостатки — их устранение и есть идея предлагаемой системы;
  - инновационность.
