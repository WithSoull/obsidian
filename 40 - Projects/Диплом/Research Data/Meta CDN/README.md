# Проверка фрагмента Meta CDN

Контрольный разбор данных для исследовательского раздела ВКР. Это проверка формата и построения признаков, а не обучение модели или оценка размещения.

## Происхождение

- Первичный поставщик — Meta. [Документация CacheLib](https://cachelib.org/docs/Cache_Library_User_Guides/Cachebench_FB_HW_eval/) описывает недельные трассы CDN за март 2023 года и разрешает их скачивание на условиях лицензии CacheLib.
- Использована копия из [коллекции CacheMon](https://github.com/cacheMon/cache_dataset). Файл: `cache_dataset_txt/2023_metaCDN/reag0c01_20230315_20230322_0.2000.csv.zst` в публичном бакете `cache-datasets`.
- [Исходный файл](https://cache-datasets.s3.amazonaws.com/cache_dataset_txt/2023_metaCDN/reag0c01_20230315_20230322_0.2000.csv.zst). Получен 01.10.2026 запросом диапазона байтов 0–1048575. Сервер ответил HTTP 206; полный размер сжатого файла — 632 922 712 байт. Полный файл не скачивался.
- Python 3.14, `compression.zstd.ZstdDecompressor`: первые 3 000 000 декодированных байт, после чего последняя неполная строка отброшена. Сохранён результат `trace_sample.csv` с исходными полями; сортировка, масштабирование и переименование ключей не выполнялись.
- `OpType=1` соответствует `kGet` в [исходном коде CacheBench](https://github.com/facebook/CacheLib/blob/0f7e808335599ca5d0e935d35aad75db8dc63f16/cachelib/cachebench/util/Request.h). Код операции кэша не подтверждает HTTP-статус клиентского запроса.

Атрибуция: Meta — исходные анонимизированные наблюдения; CacheMon — открытая коллекция и копия. Первичная документация связывает лицензию трасс с лицензией CacheLib; [лицензия рассмотренной версии CacheLib](https://github.com/facebook/CacheLib/blob/0f7e808335599ca5d0e935d35aad75db8dc63f16/LICENSE) — Apache License 2.0. Разбор и таблица признаков подготовлены для настоящего исследования. Условия иных наборов коллекции не проверялись.

## Что проверено

| Показатель | Значение |
|---|---:|
| Полные строки данных | 19 543 |
| Различные ключи | 9 853 |
| Продолжительность фрагмента | 396,449 с |
| Строки с неизвестным размером | 55 |
| Строки с границами диапазона | 3 759 |
| Ключи с несколькими положительными размерами | 10 |
| Примеры признаков и меток | 3 029 |
| Положительные метки наблюдаемого обращения | 110 |

Время отсечения — `1678863689425` мс, через 180 с от первой записи. Для каждого уже наблюдавшегося ключа берётся однозначный положительный размер только из прошлых событий. Признаки — давность, число обращений и обращений диапазона за предыдущие 120 с. Цели — число наблюдаемых обращений и наличие хотя бы одного обращения за следующие 60 с. Правая граница окон исключена. Будущие события используются только для целей.

Этот короткий пример использует минутный горизонт. Часовой горизонт основного эксперимента требует полного временного окна; имеющийся фрагмент для него недостаточен.

## Ограничения

Трасса выборочная. Нулевая метка означает отсутствие *наблюдаемой* записи в окне, а не доказанное отсутствие реального чтения. Идентификаторов S3-версий и HTTP-статусов нет; `cache_hit` не является статусом успешности. Изменение размера не позволяет восстановить настоящую версию. Время первого наблюдения не является временем создания. `responseSize` нельзя без проверки считать размером всего объекта или числом полезных байтов. Поля с неизвестной семантикой не используются как признаки.

Разбор показывает, что прошлую историю и будущие метки можно разделить. Он не подтверждает репрезентативность всей трассы, пригодность полного преобразования в S3-нагрузку или выигрыш ML. Сохранение версий, ошибки, запись и удаление проверяются отдельной синтетической нагрузкой.

## Воспроизведение

Запустить из этой папки:

```sh
python3 analyze_sample.py
```

Нужна только стандартная библиотека Python. Программа проверяет порядок времени и полноту будущего окна, затем пересоздаёт `sample_features.csv` и `summary.json`. Контрольные суммы SHA-256 записаны в `summary.json`; повторный запуск должен дать те же значения. Исходный фрагмент не изменяется.
