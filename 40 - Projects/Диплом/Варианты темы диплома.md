# Варианты темы диплома

Варианты формулировки темы для [[Диплом_ГОСТ|исследовательского раздела диплома]].

1. **Разработка системы поддержки принятия решений по размещению объектов между классами хранения OpenS3 на основе прогнозирования обращений.** Полная формулировка, которая объединяет прогнозирование, рекомендации и управление размещением.

2. **Разработка системы поддержки принятия решений по управлению классами хранения объектов в OpenS3.** Короткая формулировка с акцентом на системе в целом.

3. **Разработка системы рекомендаций по размещению объектов в S3 на основе прогнозирования востребованности.** Акцент на прогнозе и рекомендациях администратору.

4. **Разработка и исследование метода размещения объектов между классами хранения OpenS3 на основе прогнозирования обращений.** Акцент на методе и экспериментальном сравнении с базовыми политиками.

5. **Разработка системы управления размещением объектов в OpenS3 с применением методов машинного обучения.** Явно обозначает использование машинного обучения.

6. **Разработка системы поддержки принятия решений по переносу объектов между классами хранения OpenS3.** Акцент на выборе и исполнении переносов.

Интеллекстуальная система поддержки принятия решений размезмещений объектов в объектном хранилище на основе прогнозирования востребованности

## Как выбрать

Если в центре диплома будет экспериментальное сравнение методов, предпочтителен **вариант 4**. Если основной результат – работающая система с объяснимыми рекомендациями, подходит **вариант 3**. **Вариант 1** наиболее полно отражает текущую постановку: прогноз обращений, рекомендации по переносу между HOT и COLD, объяснение выбора и исполнение после подтверждения администратором.

*Формулировки предварительные: окончательную тему нужно согласовать с руководителем.*
