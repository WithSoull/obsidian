
# **СПИСОК ИСПОЛЬЗОВАННЫХ СОКРАЩЕНИЙ И ТЕРМИНОВ**
СППР — система поддержки принятия решений.

ИИ — искусственный интеллект.

ML (Machine Learning) — машинное обучение.

S3 (Simple Storage Service) — модель и программный интерфейс объектного хранения данных, первоначально разработанные для сервиса Amazon S3.

API (Application Programming Interface) — программный интерфейс приложения.

SLO (Service Level Objective) — целевое значение показателя качества обслуживания системы.

SSD (Solid-State Drive) — твердотельный накопитель.

NVMe (Non-Volatile Memory Express) — протокол доступа к энергонезависимым накопителям, ориентированный на высокопроизводительные устройства хранения.

HDD (Hard Disk Drive) — накопитель на жёстких магнитных дисках.

HOT (горячий класс хранения) — класс хранения, предназначенный преимущественно для востребованных объектов и характеризующийся более высокой производительностью доступа.

COLD (холодный класс хранения) — класс хранения, предназначенный преимущественно для менее востребованных объектов и характеризующийся большей доступной ёмкостью при более низкой производительности по сравнению с горячим классом.

Lifecycle-политика — набор заданных правил управления жизненным циклом объектов, в том числе их перемещением между классами хранения.

Metadata Service — компонент OpenS3, отвечающий за хранение и управление метаданными объектов и их версий.

Storage Service — компонент OpenS3, отвечающий за физическое хранение данных объектов.

OpenS3 — разрабатываемая S3-совместимая система объектного хранения, используемая в работе в качестве платформы для реализации СППР.
