# Ручной запуск этапа 11 (если агенты недоступны)

Записано 28.10 в 21:30. Все команды выполняются в Terminal из папки рабочей копии:

```bash
cd /Users/grishinid/home/01_Coding/s3-sppr/build/wt-sim
```

Каждую длинную команду запускайте через `nohup … &`: тогда закрытие окна терминала её не прервёт. Крышку ноутбука не закрывать.

## 0. Проверить, что уже идёт

```bash
ps aux | grep "bin/experiment" | grep -v grep
```

Если строка есть, серия ещё считается: ничего не запускайте, просто ждите. Прогресс:

```bash
ls build/experiment-main/pairs
```

Всего пар 60: 6 сценариев × 10 seed. Папка с `.partial` в конце — пара, которая сейчас считается. Папка без `.partial` — готовая пара.

## 1. Продолжить основную серию, если она прервалась

**Используйте уже собранный бинарник.** `make experiment` пересобирает его, а продолжение (`-resume`) требует ровно тот же бинарник, которым серия запускалась.

```bash
nohup build/bin/experiment -config services/sppr/experiments/main.json -out build/experiment-main -resume -python "$PWD/services/sppr/ml/.venv/bin/python" > build/experiment-main.log 2>&1 &
```

Готовые пары проверяются по контрольным суммам и не пересчитываются. Недосчитанные `.partial` начинаются заново. Ход работы:

```bash
tail -f build/experiment-main.log
```

Выйти из просмотра: Ctrl+C. Сама серия при этом продолжит работать.

## 2. Отчёт по основной серии, когда все 60 пар готовы

```bash
make experiment-report EXPERIMENT_OUT=build/experiment-main
```

Таблицы будут в `build/experiment-main/report.md` (и `.json`).

## 3. Стендовая серия: ML и EWMA по 2 ч, после основной серии

Перед запуском ничего тяжёлого не должно работать: шаг 0 ничего не показывает, Docker-стенды других проверок остановлены.

```bash
nohup make stand-experiment STAND_CONFIG=services/sppr/experiments/stand-main.json STAND_OUT=build/stand-main > build/stand-main.log 2>&1 &
```

Займёт около 4,5 ч. Затем отчёт:

```bash
make experiment-report EXPERIMENT_OUT=build/stand-main
```

## 4. Накладные расходы: 2 повтора × 3 режима, после стенда

```bash
nohup make overhead OVERHEAD_CONFIG=services/sppr/experiments/overhead-main.json OVERHEAD_OUT=build/overhead-main > build/overhead-main.log 2>&1 &
```

Займёт около 3,5 ч. Отчёт:

```bash
make experiment-report EXPERIMENT_OUT=build/overhead-main
```

## Если что-то упало

- Посмотрите последние строки лога: `tail -30 build/<имя>.log`.
- Продолжить стенд или накладные расходы можно, добавив к той же команде `EXPERIMENT_ARGS=-resume` и не меняя код между запусками.
- Ничего не удаляйте из `build/experiment-main`, `build/stand-main`, `build/overhead-main`: там результаты.
- Когда агенты снова будут доступны, напишите им «продолжи этап 11 по заметке Ручной запуск этапа 11» и укажите, какие шаги выполнены.
