# Решение №1

### Объяснение

![[99 - Meta/02 - Медиа/Pasted image 20240502234817.png]]

Делаем два списка **maxL** и **maxR**, где указываем какая максимальная высота справа и максимальная высота слева. Потом делаем список **minLR**, куда записываем минимум между $maxL[i]$ и $maxR[i]$ --> уровень воды. Остается вычесть высоту суши и получаем количество воды в одном столбе.
### Решение

``` python
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        maxL = [0] * n
        m = height[0]
        for i in range(n):
            maxL[i] = m
            m = max(m, height[i])
        
        maxR = [0] * n
        m = height[-1]
        for i in range(n - 1, -1, -1):
            maxR[i] = m
            m = max(m, height[i])

        S = 0

        minLR = [0] * n
        for i in range(len(height)):
            minLR[i] = min(maxL[i], maxR[i])

        for i in range(len(height)):
            S += max(0, min(maxL[i], maxR[i]) - height[i])

        return S
```

> [!Главный факт, на котором идея с двумя указателями а не доп массивами держится]
> Высота воды это **МИНИМУМ** из *maxR* и *maxL*, это значит, что обязательно нужен указатель вплотную для стороны, где будет минимальная высота, вот поэтому и сдвигаем наименьший указатель.

### Решение

``` python

class Solution:
    def trap(self, height: List[int]) -> int:
        maxL = 0
        maxR = 0
        l = 0
        r = len(height) - 1
        water = 0
        while l <= r:
            h = min(maxL, maxR) # высота воды

            if maxL <= maxR:
                water += max(0, h - height[l])
                maxL = max(maxL, height[l])
                l += 1
            else:
                water += max(0, h - height[r])
                maxR = max(maxR, height[r])
                r -= 1

        return water
```
