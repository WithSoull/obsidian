# Объяснение

Создаем словарь, где ключ это отсортированная строка, а значение это массив слов. Чтобы его заполнить:
1) Проходимся по всем словам
2) Получаем _sorted_str_
3) Записываем слово в словарь по ключу _sorted_str_

# Решение

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = {}

        for s in strs:
            sorted_str = self.sortStr(s)
            anagrams[sorted_str] = \
            anagrams.get(sorted_str, []) + [s]

        return anagrams.values()


    def sortStr(self, s: str) -> str:
        return "".join(sorted(list(s)))
```
