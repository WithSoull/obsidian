# ТЗ. Метод потенциалов

## Условие оптимальности

Каждому $A_i$, $B_j$ — потенциал $u_i$, $v_j$.

| Клетка | Условие |
|---|---|
| Базисная ($x_{ij}>0$) | $u_i+v_j=c_{ij}$ |
| Свободная ($x_{ij}=0$) | $\gamma_{ij}=c_{ij}-u_i-v_j\geq0$ |

## Алгоритм

1. Найти опорный план ($m+n-1$ базисных клеток).
2. Вычислить $u_i$, $v_j$ из $c_{ij}=u_i+v_j$ (положить $u_1=0$).
3. Для свободных: $\gamma_{ij}=c_{ij}-u_i-v_j$.
4. Все $\gamma_{ij}\geq0$ → **оптимум**. Стоп.
5. Иначе: клетка с $\min\gamma_{ij}<0$ → построить цикл, перенести груз → п. 2.

## Неправильный баланс

$\sum a_i > \sum b_j$: добавить фикт. $B_f$ с $b_f=\sum a_i-\sum b_j$, $c_{if}=0$.  
$\sum a_i < \sum b_j$: добавить фикт. $A_f$ с $a_f=\sum b_j-\sum a_i$, $c_{fj}=0$.
