# Транспортная задача. Распределительный метод

## Постановка

$m$ истоков $A_i$ (запасы $a_i$), $n$ стоков $B_j$ (заявки $b_j$), тарифы $c_{ij}$.

$$L = \sum_{i,j} c_{ij} x_{ij} \to \min, \quad \sum_j x_{ij}=a_i, \quad \sum_i x_{ij}=b_j, \quad \sum a_i=\sum b_j$$

**Опорный план** — $m+n-1$ ненулевых перевозок (базисных клеток).

## Методы начального плана

- **СЗУ:** заполнять с ячейки $(1,1)$ → вправо/вниз. Быстро, далеко от оптимума.
- **МНЗ:** каждый шаг — ячейка с $\min c_{ij}$. Лучший старт.

## Цикл пересчёта

**Цикл** — замкнутая ломаная с поворотами в базисных клетках; одна вершина — свободная.  
**Цена цикла:** $\gamma_{ij} = \sum(\pm c_{ij})$. При $\gamma_{ij}<0$ — план можно улучшить.

## Алгоритм

1. Найти опорный план.
2. Для каждой свободной клетки построить цикл, вычислить $\gamma_{ij}$.
3. Все $\gamma_{ij}\geq0$ → **оптимум**. Стоп.
4. Выбрать клетку с $\min\gamma_{ij}<0$, перенести $\min$ по отрицательным вершинам цикла.
5. Перейти к п. 2.
