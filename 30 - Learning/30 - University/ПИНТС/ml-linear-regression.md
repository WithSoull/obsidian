# Линейная регрессия — объяснение для бэкендера

> **Контекст:** использована в ПР4 ПИНТС для предсказания длительности поездки на такси. Результат: RMSE=4072 с, R²=0.47 — линейная модель как базовый бенчмарк.

---

## Главная идея в одной фразе

Линейная регрессия — это попытка провести прямую линию (или гиперплоскость в многомерном пространстве) через облако точек так, чтобы расстояние от точек до линии было минимальным.

---

## Аналогия: средняя зарплата по опыту

Представь, что ты собрал данные: 1000 программистов, у каждого известен опыт (лет) и зарплата (тыс. руб.).

```
Опыт 1 год  → 100 тыс.
Опыт 3 года → 150 тыс.
Опыт 5 лет  → 200 тыс.
Опыт 10 лет → 350 тыс.
```

Линейная регрессия рисует одну прямую через все эти точки:

```
зарплата = 25 * опыт + 75
```

Теперь, зная только опыт нового кандидата, ты можешь предсказать зарплату. Это и есть регрессия.

---

## Как это работает математически (без страха)

### Формула модели

```
ŷ = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b
```

Где:
- `ŷ` — предсказанное значение (y-hat, "игрек с шляпкой")
- `x₁, x₂, ..., xₙ` — входные признаки (фичи)
- `w₁, w₂, ..., wₙ` — **веса** (коэффициенты), которые модель подбирает
- `b` — **смещение** (bias / intercept), свободный член

### Аналогия с кодом

Если бы ты писал это как функцию:

```python
def predict(features: dict, weights: dict, bias: float) -> float:
    result = bias
    for feature_name, value in features.items():
        result += weights[feature_name] * value
    return result
```

**Обучение** — это поиск таких `weights` и `bias`, при которых модель ошибается меньше всего.

---

## Как подбираются веса: метод наименьших квадратов

Модель ошибается на каждой точке. Ошибка на одной точке:

```
ошибка_i = (настоящее_значение_i - предсказанное_значение_i)²
```

Квадрат нужен, чтобы:
1. Отрицательные ошибки не компенсировали положительные
2. Большие ошибки штрафовались сильнее маленьких

Суммарная ошибка по всем точкам:

```
MSE = (1/n) * Σ(yᵢ - ŷᵢ)²
```

Это называется **MSE** (Mean Squared Error — средняя квадратичная ошибка).

**Задача обучения:** найти `w₁, ..., wₙ, b` при которых MSE минимален.

Для линейной регрессии это решается аналитически — есть точная формула ответа, никакого итеративного поиска. Поэтому обучение линейной регрессии **мгновенное** (в нашем эксперименте — 0.01 секунды на 80к строк).

---

## Что значит "линейная"

«Линейная» — не про прямую линию на графике, а про линейность по параметрам (весам).

```python
# Это линейная регрессия — даже если признак x²:
ŷ = w₁·x + w₂·x² + b
# Потому что она линейна по w₁ и w₂

# А это НЕ линейная:
ŷ = w₁^x + b
```

Так что полиномиальные признаки (x², x³, x·z) — это всё ещё линейная регрессия.

---

## Мультиколлинеарность — главная проблема

**Мультиколлинеарность** — когда два признака сильно коррелируют между собой.

В нашей задаче с такси:
- `pickup_latitude` и `dropoff_latitude` коррелируют
- Расстояние `distance_km` зависит и от широты, и от долготы

Что происходит с моделью:

```
Допустим, реальная зависимость:
длительность = 10 * distance + шум

Но если longitude ≈ 2 * latitude, то модель не знает,
как распределить веса — она может поставить:
  w_distance=10, w_lat=0 — правильно
  w_distance=5, w_lat=5, w_lon=2.5 — тоже правильно!
  w_distance=-100, w_lat=55, ... — тоже "правильно"!
```

Результат — веса нестабильны и огромные, модель неинтерпретируема. **Это и есть проблема мультиколлинеарности, которую решают Ridge и Lasso.**

---

## Почему у нас плохой R²=0.47

Линейная регрессия предполагает, что зависимость **линейная**. Но длительность поездки на такси — нелинейная:

- Пробки в час пик непропорционально увеличивают время
- Маршруты через центр непропорционально длиннее
- Ночью те же 5 км — вдвое быстрее

Линейная регрессия не может уловить такие взаимодействия. Для этого нужны нелинейные модели — Random Forest, Gradient Boosting.

---

## Интерпретация коэффициентов

После обучения веса можно читать напрямую:

```python
print(lr.coef_)
# distance_km: +0.52  → каждый км добавляет 0.52 к log(duration)
# hour:        +0.03  → поздний час немного увеличивает время
# vendor_id:   +0.01  → практически не влияет
```

Это главное преимущество линейной регрессии — **полная интерпретируемость**.

---

## Когда использовать линейную регрессию

✅ Когда нужна **интерпретируемость** (что на что влияет и насколько)  
✅ Когда данных **мало** (не переобучится)  
✅ Когда зависимость **действительно линейная**  
✅ Как **baseline** — отправная точка для сравнения  
✅ Когда важна **скорость** обучения и предсказания  

❌ Когда есть сложные нелинейные взаимодействия признаков  
❌ Когда признаки сильно коррелируют (→ Ridge/Lasso)  
❌ Когда нужна максимальная точность  

---

## Связь с бэкенд-разработкой

Линейная регрессия — это буквально матричное умножение:

```python
# Предсказание для всех точек разом:
y_pred = X @ weights + bias

# X — матрица признаков (n_samples × n_features)
# @ — матричное умножение
# weights — вектор весов
```

В production это исключительно быстрая операция — предсказание для 20к точек занимает 0.3 мс (в нашем эксперименте).
