### Scheme
``` scheme
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│ HEAD │───▶│Node 2│───▶│Node 3│───▶│ TAIL │
└──────┘    └──────┘    └──────┘    └──────┘
    ▲                                   │
    │                                   │
  Write                            Read + Ack
```
## Характеристики
- Вариант **синхронной репликации**
- Не теряет данные + хорошая производительность
- Используется в Microsoft Azure Storage
## Преимущества
- Гарантия сохранности данных
- Линейная масштабируемость
- Простое восстановление после сбоев
## Связь с консенсусом
- Консистентность репликации ≈ Консенсус между узлами
