### Составной индекс **Concatenated Index (Multi-Column)**
- Индекс по нескольким столбцам для ускорения фильтрации/сортировки
- Все столбцы участвуют в сортировке
- Синтаксис:
``` SQL
CREATE INDEX idx ON table (col1, col2)
```
### Покрывающий индекс **Covered Index**
- Содержит ВСЕ столбцы запроса (фильтры + проекция)
- Включенные столбцы НЕ сортируются, только хранятся
- Позволяет выполнить запрос БЕЗ обращения к таблице
- Синтаксис: 
``` sql
CREATE INDEX idx ON table (col1) INCLUDE (col2, col3)
```

### Ключевое различие
- Составной = просто много колонок с сортировкой
- Покрывающий = все нужные запросу колонки; часть с сортировкой (ключи), часть без (INCLUDE)

### Когда использовать
- Составной: фильтрация по нескольким полям с важным порядком
- Покрывающий: частые SELECT с фиксированным набором столбцов; OLAP

### Минусы покрывающего
- Больше места на диске
- Медленнее INSERT/UPDATE
- Нельзя добавлять слишком много столбцов
