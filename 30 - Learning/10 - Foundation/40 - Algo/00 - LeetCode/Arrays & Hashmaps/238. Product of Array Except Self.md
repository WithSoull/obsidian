# Объяснение

Сначала считаем префиксное произведение потом суфиксное, сделать это можно в одном цикле, можно в двух для читабельности кода, как сделал я.
# Решение

``` python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        answer = [1] * len(nums)

        p = 1
        for i in range(len(nums)):
            answer[i] = p
            p *= nums[i]

        p = 1
        for i in range(len(nums) - 1, -1, -1):
            answer[i] *= p
            p *= nums[i]

        return answer
```
