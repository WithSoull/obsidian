# Объяснение

![[99 - Meta/02 - Медиа/Pasted image 20240502061426.png]]


Алгоритм перемещения указателей такой:
1) Надо перемещать меньшую сторону, чтобы площадь могла стать больше
2) Соответственно надо чтобы новое значение стенки также было больше предыдущего (поэтому делаем не просто left += 1, а меняем left до тех пор, пока $height[left] <= old$ )

* * *
# Решение

``` python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        maxSquare = 0
        while left < right:
            a = height[left]
            b = height[right]
            S = (right - left) * min(a, b)
            maxSquare = max(maxSquare, S)

            if a <= b:
                while left < right and height[left] <= a:
                    left += 1

            elif a > b:
                while left < right and height[right] <= b:
                    right -= 1
        
        return maxSquare
```
