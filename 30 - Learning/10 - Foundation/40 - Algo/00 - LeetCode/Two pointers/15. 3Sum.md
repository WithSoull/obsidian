# Объяснение

![[99 - Meta/02 - Медиа/Pasted image 20240427010845.png]]

Мы пользуемся тем, что знаем как найти сумму для двух чисел из задачи [[20 - Work/23 -  LeetCode/Two pointers/167. Two Sum II - Input Array Is Sorted]], соответственно здесь мы *сортируем массив сразу*. 

Выбираем так скажем *опорный элемент* (называем его i-ым) и для него ищем два таких числа чтобы давали нужную сумму.

**Как обновляются указатели?**
1) *right* --> Так же как и предыдущей задаче (right -= 1, когда сумма слишком большая)
2) *left* --> Чтобы избежать дубликатов, не берем такой left, что предыдущее значение равно текущему (nums[left] != nums[left - 1]), так мы обновляем в случае если сумма попалась ровно такая, какая нужна была. Почему также не надо делать с правым указателем, потому что мы смещаем left, до нового значения, которое будет немного больше, значит сумма тоже будет больше и энивей правый указатель тоже подвинется в левую сторону
   Если сумма маленькая *left* тоже надо сдвинуть как в предыдущей задаче (left += 1)
3) *i* --> Перескакиваем через те значения, которые уже рассмотрели до этого (потому что выбор для двух других указателей был более широк, поэтому именно левый i мы обрабатываем, а все остальные, где nums[i + ?] == nums[i] мы смело пропускаем)

# Решение
```python
class Solution:
    def threeSum(self, nums):
        nums.sort()
        result = []
        i = 0
        while i < len(nums):
            num = nums[i]

            if i > 0 and nums[i] == nums[i - 1]:
                i += 1
                continue

            left = i + 1
            right = len(nums) - 1

            # find two numbers, which sum + num = 0 (sum = -num)
            while left < right:
                s = nums[left] + nums[right]
                if s > - num:
                    right -= 1
                elif s < - num:
                    left += 1
                else:
                    result.append([num, nums[left], nums[right]])
                    left += 1
                    # skip equal numbers from left side
                    while left < right and nums[left - 1] == nums[left]:
                        left += 1
                   
            i += 1
        return result

```

``` go 
func threeSum(nums []int) (answer [][]int) {
	sort.Ints(nums)
	for i, num := range nums {
		// Предыдущий такой же => все пары перебирали уже
		if i > 0 && nums[i-1] == num {
			continue
		}
		twoSum(nums, i+1, -num, &answer)
	}

	return
}

func twoSum(numbers []int, start int, target int, answer *[][]int) {
	left := start
	right := len(numbers) - 1

	for left < right {
		s := numbers[left] + numbers[right]
		if s > target {
			right--
		} else if s < target {
			left++
		} else { // left + right == target
			*answer = append(*answer, []int{-target, numbers[left], numbers[right]})
			right--
			left++
			for right+1 < len(numbers) && left < right && numbers[left-1] == numbers[left] && numbers[right+1] == numbers[right] {
				left++
				right--
			}
		}
	}
}
```
