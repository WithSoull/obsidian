# Хэш-функция

- Хэш-функция лежит в основе хэш-таблиц.
- Представляет собой функцию, которая получает на вход какой-то неизменяемый тип данных(например строку или число), а на выходе мы получаем число

# Применение

- Кэширование веб-страниц 
	``` python 
	cache = dict()
	def get_page(url):
		if url in cache:
			return cache[url]
		else:
			data = get_data_from_server(url)
			cache[url] = data
			return data
	```
- Исключение дубликатов
	```python 
	voted = {}
	def check_voter(name):
		if name in voted:
			print("Вы уже голосовали, ухади")
		else:
			voted[name] = 1
			print("У вас успешно получилось проголосовать")
	```
- Моделирование отношений (Например в [[30 - Learning/10 - Foundation/40 - Algo/113 - Data Structures/Graphs|графах]])

# Коллизии

![[99 - Meta/02 - Медиа/Pasted image 20231016093848.png]]

От хэш-функции зависит зависимость хэша от элемента, таким образом плохая хэш-функция может позволить двум разным элементам отображаться на один хэш.

- Важно выбрать хорошую Хэш-функцию которая _не будет допускать коллизии_.
- При возникновении коллизии появляется связный список

---
# Быстродействие

В **худшем** случае: Поиск, Вставка, Удаление - $O(n)$
В **лучшем** случае: Поиск, Вставка, Удаление - $O(1)$

# Коэффициент заполнения

Хэш-таблица использует для хранения данных массив, поэтому длина массива фиксированная.

> $K=m/n$, где _m_ - количество элементов в хэш-таблице, а n - общее количество доступных элементов
