- Средняя - $O(n*log (n))$
- Лучшая - $O(n*log (n))$

Алгоритм сортировки который использует принцип [[30 - Learning/10 - Foundation/40 - Algo/Разделяй и властвуй]]

# Теория

Определяем *__базовый случай__*, это будет либо *пустой массив*, либо массив с одним элементом, его сортировать не нужно. 

Рассмотрим разные случаи:

1. `[3, 2] → [2] [3] [ ]` 
   Выбираем опорный элемент, допустим 3. Теперь проходимся по всему оставшемуся массиву и разбираем элементы большие опорного и меньше него,
   
2. `[3, 2, 1] → [2, 1] [3] или 
   `[3, 2, 1] → [1] [2] [3]`
   Теперь оставшиеся массивы справа и слева мы сортируем также (в данном случае это уже будет базовый случай)


То есть *QSort* основан на рекурсии, где __база__ это массивы с длиной не более одного. А __рекурсивный случай__ это разбиение массива на три части (опорный элемент(всегда 1), больше и меньше опорного элемента (любая длина, хоть 0)

---

# Реализация

```python
def qsort(arr):
    if len(arr) <= 1:  # Базовый случай
        return arr
    else:  # Рекурсивный случай
        pivot = arr[0]  # Опорный пункт
        less = [i for i in arr[1:] if i < pivot]
        greater_or_equal = [i for i in arr[1:] if i >= pivot]
        return qsort(less) + [pivot] + qsort(greater_or_equal)

print(qsort([10, 5, 2, 3]))
```

# Лучший и худший случай

Скорость работы алгоритма зависит от того какой элемент мы выберем в качестве опорного. А это значит что если в качестве опорного мы будем раз за разом выбирать наименьшее значение, алгоритмическая сложность возрастет.

![[99 - Meta/02 - Медиа/Pasted image 20231016074341.png]]

В данном случае сложность будет составлять $O(n^2)$, потому что на каждом уровне стека(их тут 8 или же $O(n)$) мы обращаемся к $O(n)$ элементам. Это **худший** случай.

В **лучшем** случае у нас будет $O(log(n))$ уровней, каждом из которых мы обратимся к $O(n)$ элементам, это же еще и средний случай.
