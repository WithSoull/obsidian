- `> docker ps` - процессы

---
- `> docker ps -a` - все процессы (включая те которые завершены)

![[99 - Meta/02 - Медиа/Pasted image 20231120102233.png]]

---
- `> docker rm <CONTAINER ID>` - завершить процесс, можно указать `NAME` или `CONTAINER ID`, причем можно указать только первые символы этого id, например - `docker rm 91c` завершить первый процесс из таблицы сверху
---
- `> docker run -d alpine sleep 10` - создание нового контейнера 
	  `-d` - параллельный запуск, запускается как бы в фоновом режиме 
	  `sleep 10` - работает 10 секунд 
	  `--rm` - когда контейнер закончит свою работу, сразу убьется
---
- `> docker stop <CONTAINER ID>` - останавливает контейнер, но иногда долго работает
- `> docker kill <CONTAINER ID>` - убивает контейнер 
- `> docker start <CONTAINER ID>` - запуск существующего контейнера  
- `> docker images` - показывает все _image_
 ![[99 - Meta/02 - Медиа/Pasted image 20231120111656.png]]
