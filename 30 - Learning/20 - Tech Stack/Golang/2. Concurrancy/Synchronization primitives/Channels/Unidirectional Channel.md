>[!info] Определение
>Это *однонаправленный канал*, который работает в двух сценариях:
>- только на запись
>- только на чтение

### Когжа может пригодится?
Вот у нас есть канал, в который мы пишем, и передаем его в функцию, мы не хотим чтобы кто-то еще записал что-то в этот канал. Поэтому мы используем однонаправленный канал. **При этом закрыть можно только канал предназначенный для чтения.**
### API
``` go
// Только для чтения
c1:= make(<- chan bool)

// Только для записи
c2:= make(chan<- bool)
```

### Пример
``` go
package main

import "fmt"

func in(in chan<- int) {
	in <- 100
	close(in)
}

func out(out <-chan int) {
	fmt.Println(<-out) // 100
}

func main() {
	var ch = make(chan int, 1)

	in(ch)
	out(ch) // 100
}
```
