>[!important] Data race (гонка данных)
> Несинхронизироанное образение к одному и тому же участку памяти разных потоков (горутин), как минмиум один из которых осуществляет запись

>[!danger] Важный нюанс с атомарными операциями
>Что может быть загружено/сохраненов память одной операцией на одной архитектуре (то бишь *атомарно*), **может не быть на другой**. Например 64-битные операции с 64-битном процессоре и 32-битном процессоре.

>[!important] Race condition
> Ошибка проектировнаия приложения, при которой работа системы или приложения зависит оттого, в каком порядке выполняются части кода

Чтобы обнаружить гонку, мы можем воспользоться *race detector*
Например:
``` sh
go test -race pkg
go run -race src.go
go build -race cmd
go install -race pkg 
```
