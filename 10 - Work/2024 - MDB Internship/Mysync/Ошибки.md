# Частые ошибки
## Не подключается к сети
``` bash
 Network mysync-3083_mysync_net  Creating
 Network mysync-3083_mysync_net  Error
failed to create network mysync-3083_mysync_net: Error response from daemon: invalid pool request: Pool overlaps with other one on this address space
```

### Решение
- `docker network ps` - показывает активные сети (подключения)
- Что бы убить их:
```
docker ps | grep mysync | awk '{print $$1}' | xargs docker rm -f || true

docker network ls | grep mysync | awk '{print $$1}' | xargs docker network rm || true
```
