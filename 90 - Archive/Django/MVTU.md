MVTU (Model-View-Template-URL Configuration) - это патерн, которые использует Django для создания веб-приложения. Очень схож с [[90 - Archive/Сети/MVC]] (подход сохранился - декомпозиция).

Django оставило схожий подход к проектированию, но все же он слегка отличается. ***Model*** и ***View*** остались

Главные отличия заключаются в том, что теперь ***View*** просто описывает данные, а не представляет их. Для этого есть ***Templates***. Templates отображает данные в виде HTML, CSS, JS
