# Venv
1. `python3 -m venv .venv` - создание виртуального окружения с названием ".venv" (стандартное и привычное для всех название)
2. `source .venv/bin/activate` - активация вирт. окруж.
3. `deactivate` - отключение вирт. окруж.

# Django

1. `django-admin startproject django_project .  ` - создание проекта с именем "django_project". Точка в конце команды меняет иерархию файлов, не создавая лишней папки ./django_project/django_project (self-repeating зло)
2. `python manage.py runserver` - запуск сервера

# Git 
1. `git init` - создает новые репозиторий.
2. `git status`
