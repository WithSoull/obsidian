## *Главные Файлы*
### __ init__.py
Отвечает за инициализацию файлов, без него не получится импортировать файлы и других директорий
### asgi.py и wsgi.py
Позволяет работать [[90 - Archive/Сети/ASGI]] и [[90 - Archive/Сети/WSGI]] протоколам соответственно.
### settings.py
Настройки проекта
### urls.py
Определяет на какую страницу попадет пользователь по опр. адресу.
### manage.py
Содержит в себе команды для выполнения (например startproject)
___
## *Файлы приложения*
### migrations/
Сохраняет все изменения *models.py* (т. е. просто следит за действиями с БД)
### admin.py
Администрирование
### apps.py
Настройки для каждого приложения отдельно от глобальных настроек в *settings.py*
### views.py
Здесь прописывают логику запросов и ответов, они же есть request/response. 
### tests.py
Тесты :0
