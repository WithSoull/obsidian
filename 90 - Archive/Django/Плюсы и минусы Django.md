**Плюсы:**
	Сразу из "коробки" получаем уже решенные задачи (в стиле самого питона) для стандартных проблем таких как:
		1. пользовательская аутентификация
		2. тестирование
		3. формы, БД, URL, шаблоны
		4. администрирование, есть целая панель для админа
		5. возможность улучшить безопасность и производительность		
**Минусы:**
	1. Тяжек для новичков, из-за малого количества информации.


Также есть *flask* (он является микрофреймворком), но главная его проблема в том, что проект на *flask* состоит из множества пакетов, которые могут конфликтовать между собой из-за разных версий во время обновлений. А Django в свою очередь наоборот представляет собой готовый цельный каркас, где ты сам размещаешь свои web-приложения.
