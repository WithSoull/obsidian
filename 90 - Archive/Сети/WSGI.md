#протоколы 
***Расшифровка:*** Web Server Gateway Interface
Вики: https://ru.wikipedia.org/wiki/WSGI

***Назначение:*** Позволяет взаимодействовать Python-программе(которая работает на сервере, например Django) и веб-серверу. Простыми словами, это общий язык на котором разные фреймворки питона могут между собой разговаривать.
