Задача классификации - распознавание меток классов

> *Метка* - дискретное, неупорядочное значение и метка понимается, как принадлежность к какой-то группе

Т.е. на тренировочных данных есть маркер (или метка), которая говорит к какому классу, принадлежит каждое значение 

Задача - по фотографии числа необходимо определить что это за число, берем БД, в которой будет фото, к каждому из которых есть значение числа (его метка). В данном случае у нас _конечное_ число ответов.
